# CoffeBoom

A static, multi-page recreation of the café site at https://zanes.coffee/, rebranded as **CoffeBoom**. Built with Vite, React, JavaScript, Tailwind CSS, React Router (hash routing), Lucide React and Framer Motion.

Pages: Home, About us, Menu (search, category filter, sort, saved items, recent searches), Gallery (lightbox), Contact (demo form with saved draft), Order (explains the demo limit), Privacy policy, and a not-found page. Every page ends with a small ad-space placeholder.

## Quick Settings
Edit `src/settings.js` (brand, animation speed/intensity, storage prefix) and `vite.config.js` (base path).
Animation: speed `normal`, intensity `subtle`. `prefers-reduced-motion` is respected.

## Run locally
```bash
npm install
npm run dev
npm run build && npm run preview
```

## Deploy to GitHub Pages (GitHub Actions only)
1. Create a repository (for example `coffeboom`) under your account and push this project to the `main` branch:
```bash
git init && git add . && git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/Aman22kr/coffeboom.git
git push -u origin main
```
2. In the repository go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` builds and publishes on every push to `main`.
Hash routing (`/#/menu`) means refreshes and direct links work without server rewrites, and `base: './'` keeps asset paths valid under any repository name.

## Demo limitations
- localStorage (saved items, search history, contact draft) is specific to one browser and device. It does not sync and is not a real account.
- The contact form and "Order now" send nothing and take no payment. Never store passwords or payment details here.
- Contact details, social links and the map are placeholders.
- Images are linked directly from the reference site. They may change or disappear, and you should replace them with your own photos for any real use. A fallback tile shows if an image fails.
- Visual styling (colours, fonts, spacing) was inferred from page content and structure, not copied from the original stylesheet, so fidelity is approximate.
- Ad areas are empty placeholders.
- Not yet verified by an actual install, build or browser test. `package-lock.json` is generated by your first `npm install`.
